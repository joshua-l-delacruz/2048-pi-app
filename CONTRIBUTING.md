# Contributing

Focused fixes and tests are welcome.

## Reports

Include reproducible steps, the expected result, the actual result, and relevant sanitized logs. Never post Pi access tokens, cookies, credentials, private user identifiers, or production database contents.

## Pull requests

Keep changes scoped, add or update tests where practical, and document any security or trust-boundary effect. Changes to authentication, score validation, persistence, or rate limiting require an explicit security rationale.
